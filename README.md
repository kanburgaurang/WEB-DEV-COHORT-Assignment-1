# Gaurang Kanbur – Semantic HTML Resume Page

A simple semantic HTML resume page page showcasing basic information such as skills, experience, projects, education, and contact details.
This project focuses on **clean structure** and **proper use of semantic HTML tags**.

---

## Setup Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/kanburgaurang/WEB-DEV-COHORT-Assignment-1.git
   ```

2. Navigate into the project folder:

   ```bash
   cd your-repo-name
   ```

3. Open the project:

   * Double-click `index.html`, **or**
   * Open it using a browser:

     ```bash
     open index.html
     ```

No additional setup or dependencies are required.

---

## 💻 Usage

* Open `index.html` in any modern browser.
* The page will display:

  * About section
  * Skills
  * Experience
  * Projects
  * Education
  * Contact information

This is a **static semantic HTML page**, so no server or build tools are needed.
